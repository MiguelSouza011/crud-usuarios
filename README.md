# 👤 Cadastro de Usuários API

API RESTful simples e eficiente para gerenciamento de usuários (CRUD), desenvolvida com Java e Spring Boot.

## 🚀 Tecnologias Utilizadas

* **Java** (Versão 25+)
* **Spring Boot 4**
* **Spring Data JPA / Hibernate**
* **H2 Database** (para ambiente de desenvolvimento)
* **Maven**
